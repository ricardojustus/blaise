## Goal

The two D5 engines as concrete `ASREngine` implementations (C2 protocol), registered at the composition root: WAV in → timed, NORMALIZED segments out, for real, on the sample. No diarization (C4), no correction (C5), no pipeline (C7).

## Segment normalization (normative, shared, quality-bearing)

`SegmentNormalizer` (BlaiseCore, applied by BOTH engines before returning `ASRResult`; raw engine output stays verbatim in `rawPayload`). Rules, in order, against `audioDuration` read from the WAV header:

0a. **Out-of-scope-script guard:** drop segments whose letter content is majority (>50 %) non-Latin script (Cyrillic, CJK, Greek, Arabic, …). Classification is per alphabetic Unicode scalar against explicit Latin block ranges (ASCII, Latin-1 Supplement, Extended-A/B, combining diacritics, Extended Additional); digits/punctuation/symbols count neither way, so PT diacritics and Brazilian number formatting survive. Evidence: an early two-track recording — acoustic bleed drove Whisper's language ID to Russian on the mic track, producing ~340 pure-Cyrillic hallucinated segments with `no_speech_prob ≈ 0` (confidence gating is useless against this class; the guard is structural). Blaise meetings are PT/EN only by product definition.
0b. **Repetition-run collapse:** a run of 3+ CONSECUTIVE segments with identical normalized text (trimmed, lowercased, punctuation/symbol-stripped) collapses to its FIRST segment; runs of 2 are kept. Segments normalizing to empty never form runs. Same field evidence: 148 segments in 3+ identical-text repetition runs interleaved with real speech. Consecutive-only is the V1 window (the field runs are contiguous).
Rules 0a/0b run FIRST, over the raw decoder sequence — 0a before 0b so out-of-scope garbage can neither anchor nor break a run, and both before the timing rules so runs are judged on decoder adjacency. Both are counted in `NormalizationReport` (`dropped_non_latin_script`, `dropped_repetition_run`).

1. Drop segments with empty/whitespace-only text.
2. Drop segments with `end <= start`.
3. **Drop segments with `start >= audioDuration`** (entirely out of bounds — the hallucination-tail class; evidence: the real seg_a output ends with a repeated-token " É..." loop of 10 NON-empty positive-duration segments at 299.8→306.3 s on a 300.032 s file, plus 24 empty ones. Out-of-bounds content is dropped, never clamped into visibility-masking zero-width segments).
4. For boundary-straddlers (`start < audioDuration < end`): clamp `end = audioDuration`; then DROP if the retained portion is `< 50 %` of the original duration or `< 0.2 s` (probed: the hallucination loop's first member 299.82→300.82 straddles and retains only 21 % — clamping alone would smuggle it into the transcript; a legitimate final word retains ≫ 50 % and survives).
5. Resolve floating-point overlaps: if `next.start < prev.end`, set `next.start = prev.end`; if that empties the segment, drop it. (Observed FP noise ~1e-14.)
5b. Word timings inside surviving segments are clamped to their segment's final bounds; words falling entirely outside are dropped (keeps the AC bounds assertions true at word level).
6. Post-conditions (asserted): strictly monotonic starts, non-overlapping, within `[0, audioDuration]`, no empty text.

The normalizer returns `(segments, NormalizationReport{droppedEmpty, droppedZeroLength, droppedOutOfBounds, clampedRetained, clampedDropped, overlapsResolved})`; engines log the report, and tests assert it against the real-fixture pathology. The pathology stays observable: `rawPayload` keeps everything, and C7's regression artifact can compare raw vs normalized. The whisper driver passes through `no_speech_prob`/`avg_logprob` per segment (rawPayload only in V1; gating BACKLOG).

## Serialization (both engines — normative)

**Swift actor isolation is NOT serialization: actors are reentrant at suspension points, and these methods are dominated by suspensions.** Each engine enforces single-flight with an explicit FIFO task chain, with these normative semantics:
- **Entry points vs bodies:** the PUBLIC `prepare()` and `transcribe()` are chain links. Their BODIES call internal, UN-chained implementations (`prepareBody()`, `transcribeBody()`); `transcribeBody()` invokes `prepareBody()` directly — never the public chained `prepare()` (a chained-inside-chained call would enqueue behind itself and deadlock; this distinction is the load-bearing line).
- **Link isolation:** each link is wrapped so its failure or cancellation NEVER propagates to queued links — a cancelled transcription must not poison the queue; the next call runs normally.
- **Cancellation:** a call cancelled while QUEUED observes cancellation promptly (cancellation handler around the wait-for-turn) and throws `.cancelled` without waiting for the running job; cancelled while RUNNING → subprocess killed / inference abandoned → `.cancelled`.
- Guarantees: at most one python subprocess / CoreML inference / provisioning run in flight per engine; a rebuild can never destroy a venv an in-flight call is using. Cross-engine/cross-process safety (C6 lock scheme, upgraded by that chunk): driver runs against the app-managed venv take a SHARED `flock` on `<dataRoot>/python/.lock` for the subprocess lifetime; provisioning destroy/rebuild takes the EXCLUSIVE lock try-then-wait ≤ 30 s → `.transient("python environment busy")`; provisioning's own child spawns take no lock. Tests always use temp dataRoots (asserted).
- Tested: N concurrent `transcribe()` → sequential spawn count; cancel-while-queued is prompt and leaves the chain healthy; cancel-while-running kills the process and the NEXT call succeeds.

## Engine 1 — `MLXWhisperEngine` (default; id `mlx-whisper-large-v3-turbo`, `.local`)

Whisper large-v3-turbo via mlx-whisper 0.4.3 subprocess.

- **Driver language clamp:** when no `--language` is given, the driver does NOT let `mlx_whisper.transcribe` auto-detect over all 100 languages. It mirrors the stock detection (mlx-whisper 0.4.3 `transcribe.py`: `log_mel_spectrogram` over the full audio, `pad_or_trim` to the standard 30 s window, `model.detect_language` → probability dict) but takes the argmax WITHIN `ALLOWED_LANGUAGES = ("pt", "en")` only, and passes the winner as `language=`. Rationale: meetings are always Portuguese, English, or PT/EN code-switched by product definition; unrestricted ID on an early recording rendered real PT speech as Italian-flavored orthography on the system track and Cyrillic hallucination on the mic track. `detect_language` is a pure forward pass (no sampling) — the determinism pins are unaffected — and the clamped code lands in the payload's `language` field (transcribe reports back a forced language), keeping provenance honest. An explicit `--language` hint still bypasses detection entirely.
- **Driver** (`Sources/BlaiseCore/Resources/whisper_driver.py`): stdlib `wave` + numpy (no ffmpeg), `mlx_whisper.transcribe` with `word_timestamps=True`, ONE JSON to stdout `{text, language, segments:[{start,end,text,no_speech_prob,avg_logprob,words:[{word,start,end}…]}…]}` — **word timings are a C4 dependency** (speaker-change splitting; research probed the flag works). `ASRSegment` (C2) gains `words: [ASRWord]?` (additive, decode-default nil; recorded as a C2 amendment in that spec). Argv contract: `<venv-python> driver.py --blaise-engine --audio <wav> [--language <code>]`. Exit codes: 0 ok; 2 bad input; 3 model load failure; 4 transcribe failure; detail on stderr.
- **Error mapping (explicit):** spawn failure → `.notAvailable` AND venv-sentinel invalidation (broken interpreter self-heals via next prepare rebuild); exit 2 → `.permanent("bad input: …")`; exit 3 → `.notAvailable(model)` + cache-suspect flag; exit 4 / signal → `.transient(stderr excerpt)`; stdout JSON parse failure → `.transient`; timeout → `.transient("timeout")`; cancellation → `.cancelled`.
- **Process contract:** absolute venv python; env: `PATH=/usr/bin:/bin`, `HOME`, `HF_HOME=<hfHome>`, `HF_HUB_DISABLE_TELEMETRY=1`; `HF_HUB_OFFLINE=1` iff cache integrity holds AND not suspect. **stdout+stderr drained concurrently from launch** (async pipe readers; stderr 4 KB ring) — 78-min output ≫ 64 KB pipe buffer; read-after-wait deadlocks (unit-tested with ≥1 MB dual-stream fake process). Timeout `max(600 s, 3× WAV duration)` → SIGTERM, 5 s, SIGKILL. Cancellation kills the process.
- **Orphan sweep:** at engine init, kill stray processes matching the driver path + `--blaise-engine` marker **whose ppid is 1** (launchd reparenting is exactly the observable signature of a dead parent); best-effort, logged.
- **Model-cache integrity + repair:** integrity ⇔ snapshot dir for the pinned repo exists, non-empty, no `*.incomplete` blobs. `availability()` uses it. Exit-3 sets a SUSPECT flag (marker file `<hfHome>/.blaise-suspect`, with an attempt counter inside). Repair in `prepareBody()`'s model step: integrity-FALSE → hub fetch with network allowed (resumes incomplete downloads); integrity-TRUE while SUSPECT (in-place corruption — the class resume cannot fix) → **wipe the pinned repo's cache dir, then full re-fetch** (the Parakeet engine's own pattern). Suspect + counter cleared on a subsequent successful transcribe. "Two consecutive" = two exit-3s with a completed wipe-repair and no successful transcribe between them (counter persisted in the marker file — survives relaunch) → `.permanent` with stderr.
- **Provisioning (`prepare()`, single-flight per above):**
  1. uv binary from bundle (`scripts/fetch_uv.sh`: pinned version, SHA-256 recorded in-script from the official GitHub release digests).
  2. venv (default `<dataRoot>/python/venv`; SHARED with the C6 notes driver) satisfied ⇔ sentinel `.blaise-provisioned-<sha256(python_requirements.txt)>` present. Missing/mismatched → destroy + rebuild: `uv venv --python 3.12` with `UV_PYTHON_INSTALL_DIR=<dataRoot>/python/cpython` and `UV_CACHE_DIR=<dataRoot>/python/uv-cache` (interpreter lives INSIDE dataRoot — nothing external can break the venv invisibly) + `uv pip install --no-deps --require-hashes -r python_requirements.txt` + import check → write sentinel. `python_requirements.txt` (renamed from `whisper_requirements.txt` by C6, which also grew the mlx-lm/outlines pins; the sentinel hash change migrates existing installs automatically) is HAND-AUTHORED to the exact research-pinned set; per-package sha256 hashes are fetched from PyPI's JSON API by a committed script which ASSERTS torch is absent (`uv pip compile` would resolve mlx-whisper's declared-but-unused torch dependency into the lockfile — 388 MB the research basis excludes).
  3. Model cache per integrity+repair above (disk precheck ≥ 4 GB → else `.transient("insufficient disk space: …")` — heals when space is freed).
  `transcribeBody()` invokes `prepareBody()` first (per the serialization section — NOT the chained public entry). `availability()` BEFORE first prepare legitimately reports `.unavailable("not yet provisioned")` — C2's ordering (C7 awaits prepare, then availability) makes first-run bootstrap work; stated here to prevent the landmine.
- **Config:** `venvPath` (`.path`, default `<dataRoot>/python/venv`; **override semantics: an overridden venv is externally managed — venv provisioning and ALL sentinel logic are DISABLED for it (no destroy/rebuild/invalidation ever; spawn-failure maps to `.notAvailable` without sentinel side effects), availability = import check only; `prepareBody()` still runs the MODEL-CACHE step (cache is engine-owned, not venv-owned), and suspect/repair applies normally.** Tests point at an externally-managed `<repo>/.venv` safely) and `hfHomePath` (`.path`, default `<dataRoot>/models/hf`; tests point at `~/.cache/huggingface`).
- `vocabularyHints` ignored (BACKLOG: initial_prompt experiment); provenance `vocabularyHintsApplied: false`. `languageHint` passed as `--language`; unknown/invalid hints are passed through (driver/whisper validates; failure surfaces as exit 2) and recorded verbatim in provenance.
- **Provenance:** engineVersion = `importlib.metadata.version("mlx-whisper")` run in the venv actually used (override-honest; cached per venv path per launch); runtime "mlx-whisper/subprocess"; model = pinned repo constant. Usage/costDescriptor nil.

## Engine 2 — `FluidAudioParakeetEngine` (id `fluidaudio-parakeet-v3`, `.local`)

FluidAudio **0.15.2 exact** (SPM; Apache-2.0, NOTICE/credit in README). Same actor + task-chain serialization; `AsrManager` created once per engine; fresh `TdtDecoderState` per call.

- `prepare()` = `AsrModels.downloadAndLoad(to: <dataRoot>/models/fluidaudio, version: .v3)` (461 MB; disk precheck 1 GB, `.transient` on shortfall). Repair: load failure wipes the models dir; next `prepare()` re-downloads; two consecutive failures → `.permanent`.
- `availability()`: models-dir integrity + cached last-successful-load result for this launch; named reasons. Cancellation: `Task.isCancelled` before/after inference → `.cancelled`. `languageHint` → FluidAudio language parameter (nil = auto-LID; unknown code → auto + recorded verbatim). Provenance: engine id, model "parakeet-tdt-0.6b-v3", runtime "FluidAudio 0.15.2/CoreML", engineVersion "0.15.2". Config: `modelsPath`. Usage/cost nil.
- **Segments — `TokenSegmenter`:** ports the CLI's token→word merge (thresholds cited from the CLI source file/line in a comment). Port fidelity is validated two ways, honestly scoped to available oracles: (a) synthetic unit fixtures covering each rule (gap split, punctuation split, empty timings → single full-duration segment); (b) the sample-audio integration test transcribes **seg_b** (matching the one committed default-engine sample oracle) and compares our segmenter's TEXT+boundary shape against it tolerantly (exact token-level goldens are impossible — the oracle holds post-merge output only; stated, not papered over). seg_a serves the generic engine assertions. Output passes `SegmentNormalizer`. Engine 2 POPULATES `ASRSegment.words` from its token timings (word merge precedes sentence grouping; both engines must yield non-nil words — asserted in AC2).
- **Runtime-identity note:** 0.15.2 = rev `7f963cd`, which is NOT verified to contain the research commit f3760dc. The integration test on real audio IS the runtime validation; if its output regresses against the research transcript shape, D5 is revisited before this chunk closes.

## Acceptance criteria

1. `scripts/test.sh` green. Unit tests (no network/models): driver-JSON parsing; language-clamp logic against the REAL bundled driver script (system python3 imports the module — stdlib-only at module level — and exercises `clamp_language`/`ALLOWED_LANGUAGES` with synthetic probability dicts); **SegmentNormalizer rules 0a/0b (synthetic Cyrillic/CJK drops, PT-diacritics survival, run-of-3 collapse vs run-of-2 retention, mixed interleave) and rules 1–6 + report against the SCRUBBED real-fixture** (committed fixture preserves the real seg_a timing/probability pathology; the committed scrub script replaces NON-EMPTY text with neutral tokens and preserves empty/whitespace text VERBATIM — otherwise rule 1's 24-real-empties coverage evaporates); ≥1 MB dual-stream drain test; full error-mapping table incl. spawn-failure→sentinel-invalidation; integrity/suspect/repair decision logic over filesystem fixtures (complete cache; `*.incomplete`; suspect marker); provisioning predicates incl. override-disables-provisioning; **task-chain serialization test (N concurrent calls → sequential spawn count)**; orphan-sweep matcher (ppid-1 rule); TokenSegmenter synthetic fixtures; availability reasons incl. pre-provisioning state; per-engine config namespacing.
2. **Sample-audio integration tests:** MLXWhisperEngine (`venvPath=<repo>/.venv`, `hfHomePath=~/.cache/huggingface`) on seg_a → normalized: ≥ 10 segments, strictly monotonic, within [0, 300.04], no empty text, non-nil `words` on segments, PT function words, report counts > 0 for the tail classes, provenance honest. FluidAudioParakeetEngine same + segmenter shape comparison. **Skip protocol:** a skipping test writes `<repo>/.test-skips/<test>.txt` with the reason; `scripts/test.sh` clears the dir at start; the final acceptance run requires the dir empty after ITS full-suite run — the gate is tied to the run that certifies it.
3. Provisioning test (gated `BLAISE_TEST_PROVISION=1`, **mandatory before the final acceptance gate**): clean temp dataRoot → full prepare (venv from pins+hashes, sentinel, model fetch), availability flips, 10 s WAV transcribes; THEN: interrupted-download simulation (plant `*.incomplete` → predicate false → repair fetch runs), sentinel-invalidation rebuild, and a corrupted-model exit-3 → suspect → repair end-to-end pass.
4. `scripts/fetch_uv.sh` + hashed `python_requirements.txt` (né `whisper_requirements.txt`) committed; build copies driver + uv into the bundle (exec bits preserved); `scripts/build_app.sh` green and `dist/Blaise.app` launches (AC1-style check).
5. No regression: full suite green (98 baseline + new).
